# Mise: software first

The interface is the product. Keep everyday inventory changes simple, touch controls
easy to reach, and edits intact as the phone folds or Edge enters split screen.

## First release

- Start empty; add, edit, move, remove, and consume ingredients.
- Group Fridge, Freezer, and Pantry; retain separate purchase batches.
- Preserve unknown quantities and manually entered dates. Prioritize dated batches
  without inventing food safety or package expiration claims.
- Keep staples stocked until marked low or empty; track kitchen tools separately.
- Scan UPC/EAN barcodes into a review tray. Remember corrected names. Always allow
  typing, and count repeated packages only after an intentional scan or entry.
- Copy full or selected Markdown inventory into Gemini. Download Markdown or a
  complete JSON backup. Existing AI subscriptions stay outside the app.
- Save in the current browser immediately; support optional Google/Firebase sync.
  Clearly label browser-only saving until cloud setup and sign-in succeed.
- Keep the same URL for updates, with checks before deployment and no forced reload.

## Next useful increments

1. Explicitly saved recipes, ingredient selection, and optional upgrade ingredients.
2. A cooking view with timers beside steps, screen wake lock where supported,
   and a final quantity review with adjustments during cooking.
3. Meal-prep portions and requested shopping lists. Ask about unknown quantities
   before estimating shortages; keep required ingredients and optional upgrades clear.
4. A linked grocery checklist: bought and put away are separate actions that cannot
   double-count inventory. Research store-specific brands only when requested.

Receipts, Obsidian editing/sync, inventory history, opened/thawed dates, voice,
and AI APIs are deferred. Do not add paid API requirements to the core workflow.

## Hardware later

The independent fridge client will use the same website in Edge. Current constraints:
portrait touch screen on the magnetic freezer door, about 24 by 18 inches of usable
space, approximately 16-inch display preference, white/removable mounting, roughly
one inch total depth, and $150 total target. Hardware feasibility and safety need
an actual screen/mount selection; this software release makes no hardware claim.
